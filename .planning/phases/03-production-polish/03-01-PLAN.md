| Boundary | Description |
|----------|-------------|
| user keyboard → React controlled input | Untrusted text enters `balanceStr`, `monthlyExpensesStr`, `runwayMonths` |
| derived error strings → DOM via JSX `{errors.balance}` | Error strings are rendered into the DOM |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering/Injection (XSS) | Inline error rendering `{errors.balance}` / `{errors.runway}` / `{taxWarning}` in Calculator.tsx | mitigate | Error strings are HARDCODED string literals (D-04/D-05/D-06), never interpolated with user input. React JSX `{}` auto-escapes text content. Do NOT use `dangerouslySetInnerHTML`. Do NOT concatenate user input into error strings. |
| T-03-02 | Information disclosure | Client-only SPA, no backend | accept | No PII, no secrets, no network — pure client math. No data leaves the device. |
| T-03-03 | DoS via malformed numeric input | `parseFloat` on balanceStr | accept | `parseFloat(...) || 0` already handles NaN; validation catches negatives. No infinite loops possible in pure render path. |
