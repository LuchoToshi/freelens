# Phase 1 — UI Design Contract

> Visual and interaction contract for the Calculation Engine phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none — write all components in Tailwind CSS v4 directly |
| Icon library | none — Phase 1 has no icons |
| Font | System font stack: `ui-sans-serif, system-ui, -apple-system, sans-serif` |

Source: CLAUDE.md explicit exclusion ("Three number inputs do not need a component library") and CONTEXT.md greenfield confirmation.

---

## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline label-to-value gaps within breakdown lines |
| sm | 8px | Gap between label and input within a field row |
| md | 16px | Default spacing between input fields; padding inside input boxes |
| lg | 24px | Spacing between the input section and the breakdown section |
| xl | 32px | Outer horizontal page padding on desktop |
| 2xl | 48px | Vertical padding above and below the calculator card |
| 3xl | 64px | Top-of-page breathing room before the calculator |

Exceptions: Tax rate slider thumb touch target must be minimum 44px tall (WCAG 2.5.5 AA) even though spacing scale would suggest 32px.

---

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.5 |
| Label | 14px | 400 (regular) | 1.5 |
| Heading | 20px | 600 (semibold) | 1.2 |
| Display | 36px | 600 (semibold) | 1.1 |

**Display** is used exclusively for the "Safe to Spend" output number — the primary result.
**Heading** is used for the calculator section title and the breakdown section title.
**Label** is used for all input labels, breakdown line labels, and the over-reserved state message.
**Body** is used for any supporting text (none in Phase 1; reserved for Phase 2 trust copy).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` | Page background, input field backgrounds |
| Secondary (30%) | `#F4F4F5` (zinc-100) | Calculator card background, breakdown section background |
| Accent (10%) | `#18181B` (zinc-900) | See reserved list below |
| Neutral text | `#3F3F46` (zinc-700) | Body text, labels, breakdown line values |
| Muted text | `#A1A1AA` (zinc-400) | Breakdown dashes (—) in empty/incomplete state |
| Destructive | `#EF4444` (red-500) | Not used in Phase 1 |

Accent (`#18181B`) reserved for:
- The "Safe to Spend" display number
- The slider filled track (left of thumb, indicating selected value)
- Input focus ring (`outline: 2px solid #18181B`)

No accent on generic borders, card outlines, or labels. Borders use `#E4E4E7` (zinc-200).

Rationale: This is a trust product. Calm, neutral palette. No color used for decoration. Accent appears only where the user's eye must land — the output number and the active control state.

## Component Inventory

All components are handwritten Tailwind classes. No library imports.

### Input: Balance

- Element: `<input type="text" inputmode="decimal">`
- Placeholder: `"0"`
- No currency symbol inside the input box — user types bare number
- Width: full-width within its column
- Focus state: `outline: 2px solid #18181B`, `outline-offset: 2px`
- Value formatting: none while typing (Phase 3 adds locale formatting per UX-04)

### Input: Tax Rate (Slider)

- Element: `<input type="range" min="15" max="50" step="1">`
- Default value: `30` (pre-populated — source: CONTEXT.md D-35 / Claude's Discretion)
- Adjacent display: shows current value as `30%` — updates live as slider moves
- Thumb touch target: minimum 44px height via padding on wrapper
- Track filled state (left of thumb): accent color `#18181B`
- Track unfilled state (right of thumb): `#E4E4E7`

### Input: Monthly Expenses

- Element: `<input type="text" inputmode="decimal">`
- Placeholder: `"0"`
- Starts empty (too personal to pre-populate — source: CONTEXT.md Claude's Discretion)
- Same focus state as Balance

### Input: Runway Months

- Element: `<input type="number" min="1" max="24">`
- Default value: `3` (pre-populated — source: CONTEXT.md Claude's Discretion)
- Integer only — number field, not slider (source: CONTEXT.md Claude's Discretion: "faster to type and more precise")
- Width: narrow — displays 1–2 digit values; no need for full-width

### Breakdown Display

Four lines, always visible from page load:

```
Balance              [value or —]
Tax Reserve          [value or —]
Runway Buffer        [value or —]
Safe to Spend        [value or —]
```

- Dash (`—`) color: `#A1A1AA` — visible but clearly placeholder
- Value color when computed: `#3F3F46` for top three lines; `#18181B` for Safe to Spend line
- Safe to Spend line uses Display size (36px, weight 600)
- All other breakdown lines use Label size (14px, weight 400)
- No divider lines between breakdown rows — whitespace separates them

### Over-Reserved State

Triggered when: `taxReserve + runwayBuffer >= balance`

- Safe to Spend displays: `$0`
- Below the display number, inline message at Label size (14px, weight 400, color `#3F3F46`):
  > "Your tax reserve and runway buffer use up your full balance. Nothing left to spend freely."
- No alert styling, no red color, no icon — source: CONTEXT.md D-07/D-08 ("calm, factual")

## Layout

Single-column centered layout. Max width: 480px. Centered horizontally with `margin: auto`.

```
[Page background: #FFFFFF]
  [64px top spacing]
  [Calculator card: #F4F4F5, 24px padding, 8px border-radius]
    [Heading: "What's safe to spend?"]
    [24px gap]
    [Input: Balance]
    [16px gap]
    [Input: Tax Rate — slider with live % display]
    [16px gap]
    [Input: Monthly Expenses]
    [16px gap]
    [Input: Runway Months]
    [24px gap]
    [Breakdown section: #F4F4F5 (same card background)]
      [4 breakdown lines]
    [Safe to Spend number — Display size]
    [Over-reserved message — only when triggered]
  [48px bottom spacing]
```

No sidebar. No navigation. No header. No footer. Phase 1 is a single focused screen.

---

## Interaction Contract

| Trigger | Response |
|---------|----------|
| User types in Balance or Monthly Expenses | Breakdown updates immediately on every keystroke — no debounce, no submit |
| User moves Tax Rate slider | Breakdown and % display update on every `input` event |
| User changes Runway Months | Breakdown updates immediately |
| Any input is empty or zero | Affected breakdown lines show `—` instead of a computed value |
| All 4 inputs have valid values | All breakdown lines show computed values; Safe to Spend shows result |
| `taxReserve + runwayBuffer >= balance` | Safe to Spend shows `$0`; over-reserved message appears below the number |

State machine: no intermediate loading states. Calculation is synchronous and instant. No spinner, no delay.

## Phase Boundary Notes

These items are explicitly out of scope for Phase 1 and must NOT be added during implementation:

- Inline guidance copy on the tax rate slider ("Most US freelancers: 30–40%") — Phase 2 TRUST-01
- Plain-English label explanations below breakdown lines — Phase 2 TRUST-02
- Honest limits callout — Phase 2 TRUST-03
- Input validation error messages — Phase 3 UX-01
- Mobile-specific layout adjustments — Phase 3 UX-02
- Locale currency formatting on numbers — Phase 3 UX-04
- Shareable URL encoding — v2 SHARE-01
- "Help me estimate" modal — v2 TRUST-05

The breakdown section renders data, not presentation. Keep the breakdown component structure clean so Phase 2 can annotate it with labels without rewiring the output model.
